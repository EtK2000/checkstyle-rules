# Whitelist for NoInlineJavaSourceTest.
#
# Lists test classes that currently contain inline Java fixture source (Java
# code embedded as string literals inside *Test.java). As the migration to
# resource-based fixtures (src/test/resources/.../inputs/<topic>/snippets/)
# progresses, entries are removed from this file. When the whitelist contains
# only the permanent exemptions below, the migration is complete and
# NoInlineJavaSourceTest enforces resource-only fixtures globally.
#
# Format: one bare test class name per line (no package, no #method).
# Lines beginning with '#' are comments. Inline '#' comments are also
# stripped before the class name is read.
# See docs/testing.md for the rationale.
